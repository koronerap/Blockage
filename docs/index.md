# Blockage

**A voxel level editor with Blender's habits.** You shape volume by pulling faces out and pushing
them in, then paint faces, cut objects in two, parent, light, and export clean meshes for a game
engine.

![Blockage: a small voxel scene of props and shapes, with the Outliner and the Object properties](images/editor.png)

Blockage runs on Windows, macOS and Linux. Get it from
[Releases](https://github.com/koronerap/Blockage/releases), or build it from source as the
[README](https://github.com/koronerap/Blockage#building-from-source) says.
