# Keyboard shortcuts

The keys of the Default keymap, and what the mouse does. **Preferences › Keymap** changes any
key, or switches to the *Mimic Busters* preset. F1 in Blockage shows the keys as they are set.
On a Mac, Command works wherever this says Ctrl.

## Tools

| Keys | Does |
|---|---|
| W | Select tool |
| G | Move (Transform) |
| R | Rotate (Transform) |
| E | Extrude tool |
| B | Paint tool |
| Ctrl+R | Loop Cut tool |
| S | Sculpt tool |
| Shift+M | Measure tool |
| V | View tool - the camera only |
| Q | The tool's other mode |
| X | Cycle paint mode, axes, new object |
| Shift+Tab | Snapping on or off |
| Tab | Edit Mode: into the object and out |

| Ctrl+D,  Shift+D | Duplicate |

| Alt+H | Show everything |
| L | Lock |

| F2 | Rename |
| A | Select all |

| Ctrl+I | Invert the selection |
| Ctrl+Numpad +,  Ctrl+= | Grow the voxel selection (Edit Mode) |

| Ctrl+J | Join the selected into the active |

| F3 | Search for a command |
| Shift+A | Add a shape, prop or light |
| Enter,  Numpad Enter | Keep an extrude |
| Esc | Cancel, or let go |
| M | Move to a collection |
| Ctrl+Alt+Z | Undo history |
| Shift+Q | Quick favorites |

| Keys | Does |
|---|---|
| Drag the selection | Pull it out, push it in |
| Shift+drag | Add to the selection |
| Alt+drag | Take from the selection |
